# C# Quest — спека

Личное веб-приложение: за 6–8 недель выучить 21 тему C# (программа 1-го семестра «Разработка игр и приложений») с нуля, человеку с СДВГ, гуманитарию.

## Принципы
- Один урок = 5–7 минут. Один экран = одна мысль. Никаких полотен текста.
- Объяснение «как шестилетке»: аналогия из жизни → картинка/анимация → код → практика.
- Термин вводится отдельной карточкой (слово, простое определение, аналогия). Карточки копятся в «Колоде» для повторения.
- **Ничего без объяснения.** Любая команда, слово или знак сначала получает свою карточку и разбор по частям, и только потом появляется в коде или задании. Если конструкция нужна раньше своей темы, рядом пишем «пока запомни как заклинание, разберём в теме N» (решение пользователя 22.11).
- Без стриков и наказаний. Вернулся через неделю — короткая разминка из 3 вопросов по старому.
- Мотивация: **собираешь свою игру**. Каждая тема добавляет кусок в пиксельную игру на экране «Мастерская». К концу курса игра собрана твоим кодом.
- Код пишется прямо в приложении и запускается настоящим компилятором C# (Roslyn в WebAssembly, без сервера).

## Устройства и данные
- Сайт (PWA) на GitHub Pages, работает на телефоне и компе. noindex.
- Прогресс: localStorage + синхронизация в секретный GitHub Gist. Ключ GitHub (fine-grained/classic с правом gist) вставляется один раз на устройстве в «Настройках». Слияние: объединение пройденных уровней, максимум опыта.

## Карта: 6 миров (21 тема из программы)
| Мир | Темы программы | Что добавляется в игру |
|---|---|---|
| 1. Пробуждение | 1 структура программы, namespace, переменные, область видимости · 2 типы, значимые/ссылочные · 6 преобразования, boxing, const/readonly | игра запускается, у героя появляются имя и характеристики |
| 2. Развилки | 7 ветвления и циклы · 8 break/continue/goto/return | герой принимает решения, ходит по клеткам |
| 3. Слова и сундуки | 4 строки и форматирование · 5 массивы, List, Dictionary · 3 static, enum | диалоги, инвентарь, классы предметов |
| 4. Чертежи | 9 класс и объект · 10 методы, ref/in/out · 11 конструкторы this/base · 12 инкапсуляция, свойства, модификаторы | герой становится объектом, монстры по чертежу |
| 5. Семья классов | 13 наследование, ромб, связывание · 14 virtual · 15 полиморфизм, abstract · 16 композиция/агрегация · 17 struct · 18 abstract/sealed, object | виды врагов, оружие, бой |
| 6. Контракты и аварии | 19 интерфейсы · 20 множественная и явная реализация · 21 исключения | способности, сохранения, игра не падает от ошибок |

Тема = 3–5 уровней. Последний уровень мира — босс: задача на код, результат которой видно в игре.

## Типы шагов в уровне
term (карточка термина), explain (2–3 строки + визуал), viz (интерактивная анимация), quiz, predict (что выведет код), blocks (собрать код из строк тапами), fill (вставь пропуск), bug (найди строку с ошибкой), code (пишешь сам, запуск, проверка вывода/тестов).

## Техника
- `web/` — Vite + React + TS, CodeMirror 6, стиль «фэнтези-консоль» (палитра PICO-8, пиксельные рамки, без градиентов и свечения).
- `runner/` — .NET 10 browser-wasm: Roslyn компилирует код в памяти, запуск в Web Worker, таймаут 5 с (бесконечный цикл → понятное сообщение). Ошибки компилятора переводятся на простой русский по коду CSxxxx.

## Этапы
1. Движок + карта + тема 1 целиком → фидбек по стилю.
2. Остальные темы мира 1–3.
3. Миры 4–6.
4. Колода, разминки, синк, деплой.
